# Appearance and task interactions

Settings includes an animated dark-mode switch, system theme, four accent palettes,
a custom Today greeting, comfortable or compact dashboard spacing, and an optional
decorative depth accent. These preferences are saved on the device, shared by accounts
using that device. Task data and cloud authentication are unaffected.

Swipe horizontally on a task card to reveal Complete, Tomorrow, and Add to Focus.
Quick actions exposes the same controls without a gesture. Swiping alone does not
change task data. Actions use the existing undo notification and Focus limit.
Tap a task title to expand details and edit controls. Completing a task briefly
animates its card before applying the change.

Today's progress indicator counts completed tasks among the tasks selected for
today's Focus. A brief celebration appears when the last selected task is completed;
opening an already-completed dashboard does not replay it. Reduced-motion device
settings disable transition animations. No animation libraries or network calls
were added.

Manual device checks: vertical scrolling versus horizontal swipe, completion and
undo, Tomorrow and undo, the three-task Focus limit, expanded notes, each accent in
both themes, system theme changes, preference persistence after restart, keyboard
access, and reduced motion. Android touch behavior requires a device run.
