# DailyFlow 1.0.4

This preview adds a more personal, responsive DailyFlow experience:

- swipe task actions with undo and animated completion;
- expandable task cards and Focus progress feedback;
- light/dark themes, four accent colors, custom greeting, dashboard spacing,
  and optional depth styling;
- a private profile with display name, avatar and short bio;
- a dedicated top-right profile button, separate from Privacy & Settings;
- Android notification-bar reminders with default sound and an in-app test;
- the Today dashboard, Top 3 Focus, task dependencies, follow-up history and
  end-of-day review introduced in the previous preview.

Android reminders are scheduled on the device. They can appear when DailyFlow
is in the background or closed after the app has scheduled them. This release
does not send remote social-style push messages from a server.
